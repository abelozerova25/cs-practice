git diff — показывает построчные изменения между файлами, индексом или коммитами.

git log — выводит текстовую историю коммитов.

git show — детально отображает метаданные и изменения конкретного коммита.

git log -S — ищет коммиты, в которых добавлялась или удалялась конкретная строка.

git blame — аннотирует файл, показывая автора и коммит для каждой строки





Отличие git restore от git restore --source:

Обычная команда сбрасывает незакоммиченные локальные правки до состояния HEAD. Флаг --source позволяет достать чистую версию файла из любого конкретного коммита в прошлом.

Если бы мы не сохранили изменения в коммит, команда git restore полностью и безвозвратно стёрла бы все наши текущие рабочие правки.
