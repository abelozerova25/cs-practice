git show — детально отображает метаданные и изменения конкретного коммита.

Отличие git restore от git restore --source:

Обычная команда сбрасывает незакоммиченные локальные правки до состояния HEAD. Флаг --source позволяет достать чистую версию файла из любого конкретного коммита в прошлом.

Ошибочный коммит

Отличие git reset --hard от git revert:

git reset --hard физически стирает коммиты из истории, перемещая указатель ветки назад (это опасно, если код уже отправлен на GitHub).

&#x20;git revert действует безопасно: он оставляет ошибочный коммит в истории, но создает поверх новый коммит, который зеркально отменяет все плохие изменения. В публичной истории revert использовать намного безопаснее.







Тег рабочей версии

Отличие тега от ветки:

Тег — это постоянная, неизменяемая метка ("закладка"), которая навсегда привязана к одному конкретному коммиту (например, для фиксации версии релиза).

Ветка — это динамический, подвижный указатель, который автоматически смещается вперед при создании каждого нового коммита.
