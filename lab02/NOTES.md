Git и GitHub: в чём разница



Git — это локальная система контроля версий. Она работает на компьютере, хранит историю изменений, ветки и коммиты.



GitHub — это хостинг для репозиториев. На GitHub можно публиковать Git-репозитории, делиться ими и работать над проектами вместе с другими людьми.





Использованные команды



git status — показывает текущее состояние: какие файлы изменены, какие добавлены в индекс, какая ветка активна и есть ли неотправленные коммиты.



git diff — сравнивает рабочую папку и индекс (изменения, которые ещё не добавлены).



git diff --staged — сравнивает индекс и последний коммит (изменения, готовые к коммиту).
